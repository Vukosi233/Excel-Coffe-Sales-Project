## 🚀 How to Use This Dashboard

1. Download `Coffee_Sales_Dashboard.xlsx`
2. Open in Microsoft Excel (not Google Sheets - slicers work best in Excel)
3. Use the **Slicers** to filter:
   - By Roast Type
   - By Size
   - By Loyalty Card (Yes / No)
4. Use the **Timeline** to filter by Date / Month
5. All charts and KPIs will update automatically

---

## 📈 Key Insights

- Dark roast and Medium size are the most popular combinations
- Loyalty card customers contribute a higher share of total sales
- Top 5 customers drive a large % of revenue - important to retain them
- Sales show a clear monthly trend - useful for stock and staffing planning
